# 7. Itens e interface

- Os itens são pintados (~45 cores), claros, de pouco contraste, um pouco menores e menos saturados que o vanilla. Sem pixel abaixo de L 0,30. A borda fica só 0,02 mais escura que o miolo.
- **Armaduras = figurino:** o couro é o explorador; o ferro, o cavaleiro cruzado; o ouro, o rei (tecido vermelho, enfeite dourado); o diamante, o cristal; a netherite, o samurai de laca vermelha.
- Ferramentas: o cabo conta a história (ferro com amarração vermelha; ouro com joia vermelha).
- Os corantes são frascos de nanquim. Os monstros viram pedaços em caricatura (carne podre = pedaço de rosto).
- **Interface = o caderno do explorador:** papel envelhecido (L 0,54, h 60), polaroide, desenho à mão em nanquim. A hotbar é feita de círculos escuros com anel dourado. Botões: pedra = desativado, madeira = normal, madeira clara = sob o mouse.
- O "contorno preto de 1 px" dos ícones antigos é do vanilla. **O idioma da GM nos ícones é o dos itens:** sem contorno, pintado.
